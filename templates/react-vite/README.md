# React/Vite exportável

Este template é uma saída completa e independente do construtor. Ele inclui entrypoint, estilos, configuração TypeScript/Vite, `package.json`, lockfile, build e smoke test.

## Uso

```bash
npm ci
npm run build
npm test
```

A instalação deve ocorrer em um runner aprovado; scripts de lifecycle não fazem parte do manifesto.
